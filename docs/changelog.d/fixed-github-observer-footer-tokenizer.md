- **github observer:** the `UNITARES agent:` footer of a pull request body is now found with a CommonMark tokenizer (`markdown-it-py`, in the new `observer` extra) and the standard library's HTML parser instead of a hand-written line scanner. Backticks inside an HTML `<pre>` block and backslash-escape parity now follow CommonMark, and a footer in link text or struck through no longer counts. A fixture of GitHub's own renderings pins the parser's choice to GitHub's on every test body. The observer is still dry-run only (#3277).
