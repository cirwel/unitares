- **review gate:** a sensitive diff no longer parks when one provider is out. When a required model family is still missing and no provider of that family can run (Codex out of quota leaves no OpenAI reviewer), the second-family notice now offers, and the review sweep now runs, Antigravity with a model of that family: `gpt-oss-120b-medium` for OpenAI, `claude-opus-5-5-high` for Anthropic, the default Gemini model for Google (`AGY_FAMILY_MODELS`). An Antigravity record already counts by the model it ran, so such a review supplies that family's coverage. The rule itself is unchanged: two families outside the authors, never an author's own family, and a lane model that is cooling down or exhausted on the diff is skipped.
