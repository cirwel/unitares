- **review:** `scripts/dev/ingest_review_records.py` carries each closed pull request's review history into the knowledge graph as one resolved `observation`. The history covers every review-gate round (reviewer, verdict, diff key) and, for each finding, the author's disposition. A disposition is classed as accepted, rebutted or unclassified, with its text kept verbatim, or as superseded when there is no disposition but a later round reviewed a newer diff. It is an operator-side, pull-side sibling of `ingest_ci_findings.py` and reuses that producer's REST envelope and refusal checks. The run is dry by default, needs `--apply` to write, searches before every write, and reads back the stored status. Dispositions are written by the authoring agent, so the producer records them as self-attested and calls only `knowledge`. Nothing it writes reaches `outcome_event`, the anchor tiers, calibration or the registered EISV outcome-grounding read. Native Codex inline reviews are not read yet.
