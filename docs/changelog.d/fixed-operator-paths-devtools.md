- **Paths:** `GET /api/automations` reads the census snapshot from `$UNITARES_AUTOMATION_STATE_DIR` when the writer uses one (`UNITARES_AUTOMATION_CENSUS_PATH` still wins; unset, the default is unchanged). Dev and diagnostic tools no longer assume one operator's `~/projects` layout: sibling-repo defaults follow `UNITARES_PROJECTS_ROOT` (default: the parent of the main checkout), repo-root defaults follow the script's own checkout, and plist template install examples stop with a clear message when `UNITARES_DEPLOY` is unset instead of rendering an empty path.
