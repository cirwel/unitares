- **inference:** the Codex, Claude and Antigravity host adapters are labelled as what they are on a default install: an operator extension that needs the agent orchestrator, which no Compose service starts. `list_inference_hosts` returns `extensions.agent_orchestrator` (`configured`, `host_ids`, `serves`, `note`), and each adapter record carries `extension: "agent_orchestrator"`. An adapter's `configured` now needs both `UNITARES_HOST_ADAPTER_ENABLED` and `AGENT_ORCHESTRATOR_BEARER_TOKEN`; the flag alone used to read as configured. On a server without the extension, `delegate_inference` and `consult(effort='thorough')` fail with the same `INFERENCE_HOST_UNAVAILABLE` code, but the message and recovery now say the extension is not configured and point at `consult(effort='standard')` or `call_model` instead of listing flags. `allow_degraded=true` still falls back to a standard local answer. The `consult`, `delegate_inference`, `list_inference_hosts`, `call_model` and `dialectic` descriptions say the same; `delegate_inference` moves to the `advanced` tier. No tool is hidden, no schema changes, and the interface contract digest does not move. Servers that run the orchestrator see no change in dispatch. The progressive `tools/list` shrinks by 80 B (#2507).
