- **ci(skills):** the plugin skill mirror no longer falls behind silently. `.github/workflows/plugin-skill-sync.yml` runs on every push to master that touches `skills/` and calls `scripts/dev/open-plugin-skill-sync-pr.sh`. When the mirror is in sync it does nothing. When it is behind, it commits the mirror to one automation branch (`auto/plugin-skill-sync`) in the plugin repo and opens a PR there, or updates the one already open. It never merges. It steps aside when a hand-made sync PR is open, and its push is a compare-and-swap, so a concurrent run is never overwritten. It needs a `PLUGIN_SYNC_TOKEN` secret (fine-grained, plugin repo, Contents and Pull requests read/write); without one it warns and does nothing. An operator's local deploy wrapper can call the same script. Before this, the plugin's CI checked the mirror only against its own manifest, so a stale mirror passed, and it fell behind twice on 2026-09-25/26.
