- **agent PR relay:** a new workflow reopens `claude/*` and `codex/*` PRs that hosted sessions open through the operator's account, authored instead by the `unitares-pr-relay` App (pull requests on this repository only). The original is closed with a link; branch, commits, labels and owner footer carry over, and the new body states that the branch was pushed through the operator login. It runs from master via `pull_request_target`, never executes PR code, and reads its key from a master-only environment. `relay-hold` opts a PR out.
