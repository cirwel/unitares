- **Hub (portal-hub-v0 H2a):** a new `elixir/portal` app, the hub's shell. It binds loopback only and refuses to boot on any other address. It answers for one Host and port (default `127.0.0.1:8791`, sockets included), accepts one LiveView Origin, and puts every page and socket mount behind an operator guard. Until the sign-in handoff lands, that guard refuses everyone. A `portal` CI job runs its boundary tests.
