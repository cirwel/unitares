- **README install section names the port overrides and the first client call.** A cold-start install test (a fresh agent following only the README, on a host where 8767 and 8788 were already taken) found two gaps. First, the README printed `http://localhost:8767` and never said the host ports can move, so the agent had to find `GOVERNANCE_HOST_PORT` and `LEASE_PLANE_HOST_PORT` in the install manual and the Compose file comments. The lease-plane port, 8788, was not mentioned at all. Second, the README never showed what a client does first, so the agent assembled its first call from the integrating-agents chapter. The install section now names both overrides with a link to the Docker quickstart, and says that an agent starts with `start_session(force_new=true)` and passes the returned `client_session_id` on every later call, because that is what ties its writes to its own process. The one-command install, the README's single install block and its length budget are unchanged. The full workflow, including `sync_state`, `record_result` and declared handoffs, stays in the operator manual's integrating-agents chapter.
