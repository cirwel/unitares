- **eisv:** the behavioral sensor's drift input now keeps only agent-local components (`UNITARES_SENSOR_DRIFT_AGENT_LOCAL`, default on, instrument era `SD1`). It was the full governance drift-vector norm, which on this path carried a constant stability term (0.2 for every agent) and the server-wide tactical calibration bin, so S was one number for agents that supply no complexity divergence. The input is now the agent's supplied complexity divergence and its own tactical calibration error, or no reading when neither exists. `derivation.drift_input` records what was used and what was left out. The drift vector and the ODE are unchanged. Set the flag to `0` to restore the full norm.
