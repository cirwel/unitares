- **eisv:** a behavioral axis with no supplied base term can now be held instead of filled with a constant (`UNITARES_HOLD_UNREAD_AXES`, default off; turning it on is a separate step that starts instrument era `HU1`). With the flag on: The smoothed value keeps its last reading, `V` steps only when `E` and `I` were both read, the first reading on an axis seeds it, and the assessment scores an axis only while it has a reading from the last 10 check-ins. Unscored axes are listed in `behavioral.assessment.unscored_axes`. The legacy ODE anchor and the component record are unchanged. With the flag off (the default), the arithmetic is unchanged.
