- **eisv:** a behavioral axis with no supplied base term is now held instead of filled with a constant (`UNITARES_HOLD_UNREAD_AXES`, default on, instrument era `HU1`). The smoothed value keeps its last reading, `V` steps only when `E` and `I` were both read, the first reading on an axis seeds it, and the assessment scores an axis only while it has a reading from the last 10 check-ins. Unscored axes are listed in `behavioral.assessment.unscored_axes`. The legacy ODE anchor and the component record are unchanged. Set the flag to `0` to restore filling.
