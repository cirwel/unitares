- **ops/pr-queue:** A head of queue whose arm is refused by the `gh` wrapper before any call reaches GitHub (`PR_QUEUE_ARM_REFUSAL_EXIT`) stops holding the PRs behind it once it has been refused `PR_QUEUE_ARM_REFUSAL_TICKS` times (default 12) on one commit: the queue posts a notice, keeps trying that PR every tick, and considers the next one. Unset, the default, behaviour is unchanged.
