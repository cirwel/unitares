- **residents:** The Watcher code-scanning resident (`agents/watcher/`) is no longer shipped in this repository; a deployment that runs one keeps it in its own deployment repository as an SDK client. Core keeps only the reader side of the state-location contract (`src/watcher_state_reader.py`). Tooling that called the in-repo agent (`scripts/dev/housekeeping_inventory.py`, `scripts/dev/autopilot_closeout.py`, the opt-in `watcher` collector in `scripts/ci/surface_findings.py`) now finds a Watcher through `UNITARES_WATCHER_AGENT` and skips when it is unset. Vigil no longer rebuilds Watcher's calibration floor or runs its commit scan; the Watcher's own schedule does. The check that a Watcher's pattern ids match `src/violation_taxonomy.yaml` now belongs with that Watcher.
