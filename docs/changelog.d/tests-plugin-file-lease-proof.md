- **plugin file leases:** the Docker Quickstart job now proves the companion governance plugin's edit hooks against the real lease plane of the Compose stack. Until now the plugin's file-lease tests stopped at a fake HTTP server, so nothing showed that its PreToolUse acquire, the `held_by_other` refusal and its PostToolUse release work against the service a new operator actually runs. A new step checks out `cirwel/unitares-governance-plugin` at one pinned commit and runs `scripts/ci/plugin_file_lease_proof.py`, which calls the plugin's own `run-hook.cmd pre-edit` and `post-edit-release` entry points with Claude Edit payloads. Session A acquires a lease on one file (exit 0). Session B, editing the same file from a second git worktree of the same repository, is refused with exit 2 and a message naming A's lease. After A's release, B acquires. Each step is also checked against `/v1/lease/status`, and the hooks run with `UNITARES_FILE_LEASES_REQUIRED=1`, because they fail open by default and an unreachable lease plane would otherwise also exit 0. The step passes the Compose default bearer explicitly until the pinned plugin commit includes its loopback fallback. It covers the Claude host payload and one file per edit only, and it does not show that a client without the plugin is stopped.
