- **Read-only keys:** `UNITARES_READ_ONLY_TOKENS` (comma-separated, each at least 32 characters) holds keys that can only read: `GET /v1/timeline` and the `/ws/eisv` stream accept one, in local and strict posture alike, and every other route refuses it as an unknown token. For a client that only reads, such as the operator hub's timeline (operator decision 2026-10-27). Unset, nothing changes.
