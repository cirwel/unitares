- **Read-only keys:** `UNITARES_READ_ONLY_TOKENS` lists digests of keys that can only read, as comma-separated `sha256:<64 hex>` entries, so the service environment carries no secret. `GET /v1/timeline` and the `/ws/eisv` stream accept such a key, in local and strict posture alike, and every other route refuses it as an unknown token. A malformed entry disables them all. For a client that only reads, such as the operator hub's timeline (operator decision 2026-10-27). Unset, nothing changes.
