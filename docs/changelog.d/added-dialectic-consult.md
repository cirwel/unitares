- **dialectic:** `dialectic(action="consult")` files an outside verdict on a review (a Codex or other-model consult, a subagent council seat) as a governed transcript record stamped `reviewer_kind: "external_consult"`, with the filer's role (paused agent, reviewer or third party) and the phase at filing. It needs no reviewer slot, so any bound agent can file one on any session, open or closed. It has no authority: it never advances a phase, never counts as a verdict (`agrees` stays NULL; the stated position is kept in `observed_metrics.consult.position`), and never refreshes the session's liveness clock, so it cannot overturn a standing rejection or hold a stalled session open. A session keeps at most 8. The previously documented route, an antithesis with `reviewer_kind="external_consult"`, needed the reviewer slot, which the orchestrated reviewer takes within about a minute, and had never been used (0 rows). What it does not claim: a consult is not an independent review of the session's thesis unless the model that produced it was independent of the author, and the server cannot verify that; `reviewer_provenance` is descriptive, never identity proof. Multi-seat review (a council as one record with several seats) is not built. Interface contract 1.22.0.
