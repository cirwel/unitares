- **dashboard / REST:** new read-only `GET /v1/timeline` returns every agent's events in one time window, merged and sorted oldest first, with a lookup of the agents they name: check-ins (marked `authored_by` `agent` or `substrate`), graded outcomes (with the `reported_confidence` they grade), pauses, resumes and archives, knowledge writes, declared lineage, and dialectic sessions. `hours` (default 6, up to 168), `agent_id`, `kinds`, `limit` per kind (default 500, up to 2000; `truncated` names each kind that reached it), `include_substrate` (default on) and `include_trajectory` (the server's own `trajectory_validated` re-scores, default off). An unknown parameter or kind is a 400, not a wider read. It is the data source for a planned per-agent timeline view in the dashboard; nothing renders it yet.
