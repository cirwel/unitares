- **The Docker quickstart runs the AGE knowledge backend.** `docker-compose.yml` and `.env.example` now set `UNITARES_KNOWLEDGE_BACKEND=age`, so a new install stores the graph over its findings (`AUTHORED`, `RELATED_TO`, `TAGGED`, `RESPONDS_TO`, `SUPERSEDES`) and search results carry a `superseded_by` pointer. An existing quickstart install that ran `postgres` rebuilds the graph from its rows on the first knowledge-graph access after the switch; set `UNITARES_KNOWLEDGE_BACKEND=postgres` in `.env` to keep the old behaviour. A native install with the variable unset still resolves to `postgres`. New `docker-compose.full.yml` adds semantic search (`bge-m3`, CPU torch) and hybrid ranking in a locally built image; the reranker and graph expansion stay off. The quickstart CI job now proves that stored findings get their graph edges.
