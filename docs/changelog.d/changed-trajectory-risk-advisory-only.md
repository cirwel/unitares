- **eisv:** the trajectory-identity enrichment no longer rewrites the agent-visible `metrics.risk_score`. The trust-tier and lineage-anomaly delta (+0.15 anomaly, +0.05 tier ≤1, −0.05 tier 3) is still reported as `metrics.trajectory_risk_adjustment` (`delta`, `reason`, `applied: false`) and still raises the `trajectory_adjustment` event, but the risk an agent is told now equals the persisted, pre-enrichment value in `core.agent_state`. `lineage_similarity` drifts toward a floor with identity age rather than discriminating agents, so an agent-facing risk number should not depend on it. The `original`/`adjusted` fields are removed because nothing is adjusted.
