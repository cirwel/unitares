- **inference:** Antigravity (`agy`, Google subscription) is the third strong-model host adapter, `antigravity:host-adapter`, callable through `delegate_inference` and as a `consult(effort="thorough")` peer. It runs in plan mode and its sandbox from an empty temporary workspace with an allowlisted environment, and a turn that stalls on a denied command or the output limit is resumed in the same conversation; usage is summed across resumed turns. `consult` now chooses among three peers: a caller is never sent to its own model family (the reported model or provider decides first, then the harness, client and user agent), and the first available peer wins. `UNITARES_HOST_ADAPTER_DISABLED_HOSTS` switches single hosts off while the rest stay on. Google API credentials (`GEMINI_API_KEY`, `GOOGLE_CLOUD_PROJECT`, `GOOGLE_APPLICATION_CREDENTIALS`) are no longer passed to `agy` in any lane, including the dialectic reviewer's Antigravity backend and the PR review gate, so these stay subscription lanes by construction; an `agy` that authenticates with an API key instead of its keyring login no longer works there.
