- **lifecycle:** a write refused because the agent is paused now writes a `paused_write_refused` audit event (`details.surface` = `check_in` or `shared_memory_write`, plus `paused_at`). Before this, both pause gates returned `AGENT_PAUSED` and recorded nothing, so the trail went blank for the paused agent and nothing could count how often a pause actually held a write. What is refused is unchanged.
