- **eisv:** readers that run on a schedule or serve live traffic now say when their window spans an EISV instrument change instead of silently pooling it. The doctor's `signal_degeneracy` check names the crossed changes in its detail (its message, and so its finding fingerprint, is unchanged), and the telemetry-health route returns them under `eisv_instrument_eras` (`eisv.era_crossing.v1`), with a separate `calibration` report reaching back to the oldest state row its outcome pairing used. Neither refuses, and a registry read error never fails either. `src/eisv_eras.py` gains `crossing_report` and `crossing_note`.
