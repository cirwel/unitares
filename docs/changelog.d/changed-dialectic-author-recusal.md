- Interface contract 1.47.0: Dialectic review requests recuse requester-declared author-agent UUIDs. Terminal decisions now bind a durable resolution-effect record and the exact durable transcript revision they resolve. The operator-only `reconcile_effect` action inspects pending, applying, applied and unknown-partial effects without automatically replaying ambiguous work; `mark_applied` is fenced by the exact `effect_updated_at` returned by the operator's inspect. Ambiguous reviewer claims fail closed, an in-flight BEAM saga never opens a second Python terminal writer, terminal writes clear stale facilitation requests, and a read-only operator inventory surfaces every non-applied effect.
- Dialectic resolution claims now carry a monotonic session generation and the session activity timestamp observed at claim time. Terminal commit locks and advances the exact reserved generation in the same PostgreSQL transaction as the session decision and effect outbox; reverted claims are never resurrected. Python maintenance writes bind that generation and exclude in-flight claims, liveness binds its observed activity timestamp, and first-responder reviewer assignment commits atomically with the antithesis. Deployments must apply migrations 075/077/078 and quiesce both writer runtimes during the code cutover.
- Expired pauses remain reported as write-held until their token-fenced durable resume commits. State reads expose `expiry_eligible` separately so a failed or delayed expiry cannot be mistaken for permission to write.
- The dialectic resolution-effect inventory now follows the server's `DB_POSTGRES_URL` by default, while retaining the legacy environment-variable fallback and an explicit `--dsn` override.
