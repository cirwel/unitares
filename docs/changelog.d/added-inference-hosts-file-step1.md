- **Inference hosts file, step 1:** `src/inference_config.py` defines the shared vocabularies for inference hosts and jobs (model families, egress classes, host kinds, the closed set of jobs and their modes) and parses the operator file named by `UNITARES_INFERENCE_HOSTS_FILE`, per `docs/proposals/active/inference-hosts-config-v0.md`. A file that does not load is reported with the line or field at fault and never falls back to the shipped defaults; with no file named, nothing changes. `list_inference_hosts` and `describe_inference_host` gain a descriptive `family` field, and the doctor gains an `inference_hosts_file` check. No routing reads the file yet (step 2).
