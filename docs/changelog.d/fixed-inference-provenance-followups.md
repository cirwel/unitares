- **inference provenance:** a delegated result now carries `model_reporting_status` (why `model_used` is empty when a host CLI reports no model) and `model_reroutes` (a mid-run model switch the host observed), which the host adapter already produced but the delegated lane dropped. Both reach the consult diagnostics and the `consultation` audit row. A failed upstream attempt now carries the attempted host's registry `host_id`, `provider_kind` and `privacy_class` (never the raw base URL), on both lanes, so the consult failure details and the audit row say whether a failed call was tried locally or off-box. The `call_model` and `delegate_inference` descriptions now say that a successful call also runs one governance update on the caller's state (Energy accounting). What this does not do: it does not change or remove that update, which waits until after the 2026-12-01 registered read so the read's inputs stay fixed; it does not record which Ollama build served a call (tags carry no digest); and a failure before any host is resolved still names no route (#NNNN).
