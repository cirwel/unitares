- **eisv:** with unread axes held (`UNITARES_HOLD_UNREAD_AXES=1`, default on), an agent past cold start that has supplied too few behavioral readings no longer has its verdict decided by the Φ cold-start prior. No verdict is drawn: it proceeds with driver `insufficient_reading`, risk 0 and a provisional grade, and the response says nothing was measured. Cold start ends at check-in 6 (`BehavioralEISV.checkin_confidence` at 0.3), where an agent that supplied every reading would hold authority; the Φ prior owns check-ins 1–5. The verification floor and structural pauses are unchanged, and setting `UNITARES_HOLD_UNREAD_AXES=0` restores the previous arithmetic.
