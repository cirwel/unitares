- **merge queue:** a delivery owner can label its own draft `ready-when-validated`; `pr-babysitter.sh` then marks it ready and queues it once the declared content has passed CI and its `review` check, so a PR no longer waits for a session to return and declare it ready. Review is always required on this route, a later push lapses the declaration, and capability, held, sensitive, fork and stacked PRs are never promoted.
