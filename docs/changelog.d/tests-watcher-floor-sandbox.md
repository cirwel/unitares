- **watcher tests:** the Watcher tests under `agents/watcher/tests/` no longer read the developer's calibration floor. `floor_state.DEFAULT_STATE_DIR` is bound when the module is imported, which happens before the directory's per-test sandbox sets `UNITARES_WATCHER_DATA_DIR`, so the 54 tests there that render findings read the real `~/.unitares/watcher/pattern_floor.json`. Where that floor had a `P006|app` bucket with `ci_lower` below 0.3, the listing tests' medium `P006` fixtures were demoted to low and never shown, and 19 tests in `agents/watcher/tests/test_agent.py` failed locally while CI, where no floor demotes those fixtures, passed them. The failures also came and went by UTC day: they showed only on days the exploration probe did not pick that bucket. The directory conftest now repoints the floor's default dir into each test's sandbox, and an isolation guard pins it by path so a regression fails on CI as well. With the fix, an audit-hook probe over `agents/watcher/tests/` and the `tests/test_watcher_*` files saw no test open any file under the real Watcher state dir.
