- **silence probe:** a governance restart no longer re-announces an outage that was already alerted. Whether a silence episode was already alerted now comes from the alert events `audit.events` already holds (any `lifecycle_silent_critical` for the agent since its last activity), not only from in-memory sets that every restart emptied; activity after the alert starts a new episode that alerts normally, and an unreadable audit store fails open. The WARNING tier is de-duplicated the same way, including the warning sent instead of CRITICAL when a proxy shows the host alive. No new storage.
