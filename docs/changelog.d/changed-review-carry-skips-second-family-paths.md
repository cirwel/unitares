- **review gate:** a review is no longer carried across a base merge when the PR touches a second-family path (the paths `scripts/dev/review_policy.json` lists, read from the base branch). A base merge that moves the diff key of such a PR now needs a fresh review on the new key rather than carrying the old one, as before the carry. A base merge that leaves the PR's files untouched keeps the key, and its records still count. A PR whose changed paths cannot be read is treated the same way. Every other PR keeps the carry across clean automatic base merges (operator decision, 2026-09-28).
