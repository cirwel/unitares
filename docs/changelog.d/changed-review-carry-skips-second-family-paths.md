- **review gate:** a review is no longer carried across a base merge when the PR touches a second-family path (the paths `scripts/dev/review_policy.json` lists, read from the base branch). A base merge can change how a PR's unchanged lines behave, and on those paths that is now reviewed again rather than carried; the diff is decided on its own key, as it was before the carry. A PR whose changed paths cannot be read is treated the same way. Every other PR keeps the carry across clean automatic base merges (operator decision, 2026-09-28).
