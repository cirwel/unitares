- **suite isolation:** the test suite no longer writes into the checkout's `data/`. The audit log, process heartbeats, state locks and the two calibration state files took their default path from the checkout, and `tests/conftest.py` redirected none of them, so every run appended test agents to `data/audit_log.jsonl` (a long-lived dev checkout reached 795MB / 1.4M lines, unrotated because rotation runs only in the live server) and left heartbeat and lock files behind in every worktree. The defaults are now module constants the suite redirects. `UNITARES_AUDIT_LOG`, `UNITARES_PROCESS_DIR`, `UNITARES_LOCK_DIR`, `UNITARES_CALIBRATION_STATE` and `UNITARES_SEQUENTIAL_CALIBRATION_STATE` do the same for servers the suite spawns as subprocesses, following `UNITARES_TOOL_USAGE_LOG`. Unset, every path is unchanged. The startup stale-lock sweep, `cleanup_stale_state_locks()` without a root, and the distributed-lock file fallback now resolve the same lock directory `StateLockManager` writes to, so an override moves writer and sweeper together; `bootstrap_server` drops its `project_root` argument. The zombie-reaper test runs against an empty process table, since heartbeats now go to a tmp dir no host server writes. Empty directories some tests still create under `data/` are not covered (#2417).
