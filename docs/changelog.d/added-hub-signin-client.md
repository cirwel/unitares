- **Hub sign-in (the hub's half):** the local operator hub (`elixir/portal`) signs in by borrowing a dashboard passkey sign-in. `/signin/start` sends the browser to the dashboard's approval page with a PKCE challenge; `/auth/callback` checks the state and exchanges the one-time code over the governance server's owner-only socket; every request then asks the server whether the hub handle is still live, so signing out of the dashboard signs the hub out too. Configured by `PORTAL_GOV_ORIGIN`, `PORTAL_GOV_SOCKET` and `PORTAL_HUB_TOKEN`; without them the hub refuses everyone (portal-hub-v0 H2c).
