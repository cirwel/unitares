- **Installation:** `start`, `stop`, and `logs` support configured macOS Homebrew services, selected automatically by the packaged CLI or explicitly with `--homebrew` from source. Startup verifies port ownership and the installed schema before starting writers, reuses existing services, and checks deep health. Stop preserves shared PostgreSQL/Redis services. Native package operations cannot accidentally fall through to Docker update/model commands. Package publication and first-time database/configuration setup remain separate.
