- **Agent orchestrator:** with `AGENT_ORCHESTRATOR_PROFILES_GENERATE=1`, the orchestrator reruns the profiles generator every minute from the inputs recorded beside the file and reloads the result. It refuses profile spawns while a run failed, ran past its interval, or left a file that does not load, and reports this as `generation` on `/v1/health`. A hand-maintained profiles file is unaffected. The doctor's `orchestrator_profiles` check fails while regeneration fails (inference-hosts-config-v0 step 4b; operator decision 2026-10-27).
