- **sdk:** `UnitaresClient.consult()` and `SyncGovernanceClient.consult()` call the server's `consult` tool and return a new `ConsultResult` (`advice`, `status`, `consultation_id`, `completion`; `error`/`error_code` on refusal). `effort` is omitted unless given, so the server infers it from `host_id`, and the client timeout (495s) stays outside the server's 480s consult budget so the SDK's single transient retry never re-sends a consultation still running. `call_model()` on both clients now emits a `DeprecationWarning` pointing at `consult()`, matching the server tool's deprecation; it still works and is still the only way to set `model`, `temperature` or `max_tokens` on an HTTP host. No SDK version bump here.
