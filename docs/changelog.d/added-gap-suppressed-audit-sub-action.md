- **audit:** the `attest_gap_suppressed` event now records what it suppressed as structured fields: `original_action`, the raw `original_sub_action`, and `sub_action_class` (`risk_pause`, `cirs_block` or `other`). Until now the event stored only the `original_reason` text, so nobody could read from the audit trail how often gap suppression downgrades a high-risk `risk_pause` compared with a CIRS block or a structural pause. Telemetry only: the downgrade rule, its window and the returned decision are unchanged, and a test pins the returned decision byte for byte. Rows written before this change carry none of the new fields.
