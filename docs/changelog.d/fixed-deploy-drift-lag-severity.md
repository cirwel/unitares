- **deploy-drift doctor:** a live checkout a few merged commits behind origin is now a warning, not a critical finding. It becomes critical once it is more than 20 commits behind (`DEPLOY_DRIFT_BEHIND_CRITICAL_COMMITS`) or has stayed behind for 24 hours (`DEPLOY_DRIFT_BEHIND_CRITICAL_AGE_SECONDS`). Before this, every lag was graded critical, and in one window 20 of 23 findings reached the operator's urgent channel, mostly the plugin skill mirror trailing by a commit or two. A checkout on the wrong branch or a pinned checkout behind its declared version is still critical at once; a pending restart is still a warning.
