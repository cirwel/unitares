- **Dialectic reviewer hosts from the inference hosts file (step 3):** the orchestrated reviewer's ordered host list now comes from the `dialectic_reviewer` job in the operator's inference hosts file when one is set, with hosts the file switches off removed; without a job, `UNITARES_DIALECTIC_REVIEWER_HOST(S)` apply as before, minus switched-off hosts. The server resolves the list and forwards it. A file that does not load, or a selection that leaves no callable host, is forwarded as `UNITARES_DIALECTIC_REVIEWER_HOSTS_ERROR`, which the reviewer treats as an invalid list: no host is called and the local floor cannot approve. Declared hosts in the job are not callable by the reviewer until the reviewer design's declared-host step. With no file, nothing changes.
