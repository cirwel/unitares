- **doctor, `pr_owner_footer`:** a new operator check reads open `claude/*` and `codex/*` PRs through the App runner and resolves each `UNITARES agent: <uuid>` footer against `core.identities`. It warns on a missing footer or a uuid the server never minted, and an unreadable PR list or identity table warns rather than passing. Hosted cloud sessions type the footer by hand, so this is where a missing one is noticed; `doctor_findings` escalates it like every operator check. It skips on a host without `unitares-github`.
