- **Stored findings link to similar ones again.** The parameter middleware hands the store handler `auto_link_related=None` when a caller leaves the flag out, and the handler read that None as "off", so validated stores skipped linking: in the week of 2026-10-19, 2 of 269 new findings on the reference deployment got related links. An unsent or null flag now means on; only an explicit false (`false`, `"false"`, `"0"`) turns linking off, on single and batch stores.
