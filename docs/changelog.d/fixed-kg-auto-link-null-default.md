- **Stored findings link to similar ones again.** The parameter middleware hands the store handler `auto_link_related=None` when a caller leaves the flag out, and the handler read that None as "off", so validated stores skipped linking: in the week of 2026-10-19, 2 of 269 new findings on the reference deployment got related links. An unsent or null flag now means on, on single and batch stores. An explicit false still turns linking off; on the `knowledge` router the schema reads any string other than `true`, `1` or `yes` (case-insensitive) as false, and a batch item's string is read as false for `false`, `0` or `no`.
