- **agent-facing hints:** three gaps an external agent hit while dogfooding (2026-09-24). (1) `get_governance_metrics` / `check_working_state` now declare `verbosity` (`minimal` | `standard` | `full`). The handler has read it since the tiers existed, but only `lite` was declared, so `/mcp/` dropped `verbosity` and an agent wanting more than the minimum could only reach `full` (~15 KB), whose size warning then said `lite=true`. The catalog, the raw-payload hint, `response_options` and the oversized-response hint now name `verbosity='standard'`; `response_options.current` reports the tier actually served: the handler and the envelope now resolve it through one function, which changes two inputs. An explicit `lite: null` now serves the default `minimal` (it built `full` while the envelope reported `minimal`), and on REST `get_governance_metrics`, the one unvalidated route, a string the schema reads as false (`"no"`, `"0"`, `"off"`) now serves `full` instead of `minimal`, as every validated route already did. `verbosity` is matched exactly, as the handler always matched it, and validated routes (`/mcp/`, REST `check_working_state`) now refuse an off-list value such as `"Standard"` that they used to ignore. `response_options.current` for `check_working_state` now names the tier (`minimal` / `standard` / `full`) where it said `lite` / `full`. Interface contract 1.15.0. (2) `record_result` returns `corroboration_hint` when a self-attested claim grades `claim_only`: the reference keys that raise it to `self_report_with_refs` (one each from the grader's pr, commit, ci and test families; the command family is left out because its keys are tool-observation triggers; a test grades every advertised key alone and beside a partial tool description), and that self-attested detail is capped at `tool_observed` whatever it carries. It deliberately does not list the shapes that reach `tool_observed`: that grade is also the calibration admission weight, a caller can reach it by description alone, and whether it should is an open operator decision, so the hint only advertises grades below the calibration floor. Response-only, never persisted. (3) dialectic `wait_assessment` gains `poll_after_s`, the remaining reviewer budget as a number, set only while `too_early`; it is null when overdue or when no budget exists, rather than an invented interval.
