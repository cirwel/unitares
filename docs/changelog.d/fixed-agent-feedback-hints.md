- **agent-facing hints:** three gaps an external agent hit while dogfooding (2026-09-24). (1) `get_governance_metrics` / `check_working_state` now declare `verbosity` (`minimal` | `standard` | `full`). The handler has read it since the tiers existed, but only `lite` was declared, so `/mcp/` dropped `verbosity` and an agent wanting more than the minimum could only reach `full` (~15 KB), whose size warning then said `lite=true`. The catalog, the raw-payload hint, `response_options` and the oversized-response hint now name `verbosity='standard'`; `response_options.current` reports the tier actually served: the handler and the envelope now resolve it through one function, which changes two inputs. An explicit `lite: null` now serves the default `minimal` (it built `full` while the envelope reported `minimal`), and on REST `get_governance_metrics`, the one unvalidated route, a string the schema reads as false (`"no"`, `"0"`, `"off"`) now serves `full` instead of `minimal`, as every validated route already did. `verbosity` is matched exactly, as the handler always matched it, and validated routes (`/mcp/`, REST `check_working_state`) now refuse an off-list value such as `"Standard"` that they used to ignore. `response_options.current` for `check_working_state` now names the tier (`minimal` / `standard` / `full`) where it said `lite` / `full`. Interface contract 1.15.0. (2) `record_result` returns `corroboration_hint` below the self-attested cap: the reference keys that reach `self_report_with_refs`, the structured shapes that reach `tool_observed`, and that self-attested detail is capped there whatever it carries. The hint's tool-observation shapes are the constants `tool_observation_triggers` reads, its reference keys are derived from the grader's claim-field families (one per family), and a test grades every advertised key. Response-only, never persisted. (3) dialectic `wait_assessment` gains `poll_after_s`, the remaining reviewer budget as a number, set only while `too_early`; it is null when overdue or when no budget exists, rather than an invented interval.
