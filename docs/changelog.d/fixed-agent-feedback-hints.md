The hint's tool-observation shapes are the constants `tool_observation_triggers` reads, its reference keys are derived from the grader's claim-field families (one per family), and a test grades every advertised key. Response-only, never persisted. (3) dialectic `wait_assessment` gains `poll_after_s`, the remaining reviewer budget as a number, set only while `too_early`; it is null when overdue or when no budget exists, rather than an invented interval.
