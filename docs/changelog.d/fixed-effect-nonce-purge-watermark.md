- **effect binding:** a clock set back after a nonce purge no longer reopens replay. The purge of `effects.consumed_nonces` deletes a row once its grant has expired past the retention margin, so a grant whose row was purged could verify again, and be consumed a second time, if the verifier's clock was later set back to before that grant's `exp`. Each purge now records the latest `grant_exp` it deleted in one reserved row of the same table (nonce `purge-watermark:v1`), and `/v1/effect-veto` refuses (`binding_replayed`) any grant whose `exp` is not after that watermark. A grant carrying the reserved nonce is refused (`binding_bad_nonce`). While the clock is set back that far, fresh grants are refused too, until it passes the watermark again. No migration is needed: until the first purge the table has no watermark row and consumes behave as before.
