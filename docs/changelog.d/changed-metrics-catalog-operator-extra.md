- **metrics catalog:** the shipped catalog behind `GET /v1/metrics/catalog` and the `POST /v1/metrics` write gate now names only product metrics. The seven series about this operator's own deployment (`tokei.unitares.src.code`, `tests.unitares.count`, `governance.sentinel.findings.7d` and the four `github.cirwel.traffic.*` series) moved next to their producer in `agents/chronicler/metrics_catalog.json`, which the server registers, `.error` twins included, only when `UNITARES_METRICS_CATALOG_EXTRA` names it. Unset (the default) lists and accepts none of them; a missing, unreadable or malformed file or entry is skipped with a `WARNING`, and an extra entry never overrides a core one. A deployment running the reference Chronicler must set the variable before upgrading, or its next scrape of those seven names is refused with 404. Stored points stay readable through `/v1/metrics/series` either way (#2526).
