- **residents:** The Chronicler metrics-scraper resident (`agents/chronicler/`) is no longer shipped in this repository; a deployment that runs one keeps it, and its metric catalog, in its own deployment repository as an SDK client. The branch-hygiene sweep moved from `agents/vigil_hygiene/` to `scripts/dev/branch_hygiene/`: it is repository tooling used by `scripts/dev/workspace_closeout.py`, not a resident. Its lease surface id and behaviour are unchanged.
