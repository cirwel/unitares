- **temporal context:** the "N knowledge graph entries added since last session" sentence in `temporal_context` (on the onboard response and on check-ins, through the `enrich_temporal_context` enrichment) can now appear. The narrator passed the previous session's end to `kg_query` as an ISO string. `created_at` is TIMESTAMPTZ and asyncpg refuses a `str` for it, so every call raised a `DataError`. The narrator caught it and logged it at debug level, and the sentence was never emitted, while the other temporal signals (long session, gap since last session, idle, high check-in density) kept working. Its unit tests mocked `kg_query` and so accepted the string. It now passes the timezone-aware datetime, and a test holds the call to that type. What it does not change: the signal still needs a previous inactive session for the same identity, so a freshly minted identity never sees it; the count reads at most 50 rows and includes every status, archived and cold among them; and the narrator stays silent when nothing crosses a threshold.
