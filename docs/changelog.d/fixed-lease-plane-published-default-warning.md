- **The lease plane warns at boot when its bearer token is the published compose default.** It names `LEASE_PLANE_BEARER_TOKEN`, never the value, and adds a second warning when the listener binds beyond loopback outside a container, whether `UNITARES_LEASE_PLANE_HTTP_IP` or `config :lease_plane, http_ip:` set the address. It does not refuse: inside the compose container it binds every interface by design, so the bind address cannot tell an exposed install from the quickstart. The digest is pinned to `docker-compose.yml` and to the governance server's copy by tests.
