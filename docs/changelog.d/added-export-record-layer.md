- **export:** `export(action='file', complete_package=true)` now includes a `record` layer read directly from storage: the agent's neutral checkpoints (`core.checkpoints`), the knowledge entries it authored and its outcome events, newest 1000 of each, with a `truncated` flag per family. Findings keep their `closure_class` and `closure_evidence`, and a superseded finding lists its replacements in `superseded_by`, read from the knowledge graph's SUPERSEDES edge (empty when the graph cannot be read). Estimator values on outcome rows sit in a separate `eisv` block (null when none were stamped). The EISV history becomes an optional layer: when the estimator's state cannot be read, the package is still written with the record and a `history_error`, and the history-only export says to use `complete_package=true`.
