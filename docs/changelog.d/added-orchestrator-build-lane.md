- The launch profiles generator writes `build.claude`, a write-capable build lane run by the new `src/mcp_handlers/support/build_lane_client.py`: Claude Code unattended in a caller-named directory with a brief the operator fixes, so a low-quota agent can commission work from one with more. The directory is accepted only at or under a root given with `--build-root` (`AGENT_ORCHESTRATOR_PROFILES_BUILD_ROOTS` in the orchestrator's `start.sh`), the brief comes from `--build-brief` (`..._BUILD_BRIEF`), extra read directories from `--build-read-root` and an MCP configuration from `--build-mcp-config`; the lane is omitted without a root and a brief, and a named but missing one is an error. The caller fills `BUILD_DIR` and optionally `BUILD_MODEL`, and may pass lineage (`lineage: caller`); one build runs at a time for up to two hours. The client runs the CLI without `--safe-mode` (project instructions, hooks and the governance plugin stay on) but with a fixed tool set, `--strict-mcp-config`, `dontAsk` with no prompts, an allowlisted environment and PATH shims that refuse `gh`, `git push` and `git add -f`; it writes `.build-lane/{started,result}.json` and `build.log` in the directory so a caller polling every few minutes outlives the orchestrator's five-minute result retention. Bash is not path-confined: the caller must build from a trusted base and copy in only what it validated (`docs/operations/agent-orchestrator-build-lane.md`).
