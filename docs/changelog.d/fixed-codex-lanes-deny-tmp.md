- **Codex lane confinement:** every codex lane's permission profile now denies `/tmp`, `/private/tmp`, `/var/tmp` and `/private/var/tmp` (those that exist), which codex's `:minimal` read set grants. A lane could otherwise read any file other users or sessions left there and return it in its answer. A deny outranks every read in codex's profile, so a lane given a workspace under one of these directories cannot read it; `under_temp_root` lets a caller refuse such a workspace with the reason.
