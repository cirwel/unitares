- **Codex lane confinement:** every codex lane's permission profile now denies `/tmp`, `/private/tmp`, `/var/tmp` and `/private/var/tmp`, which codex's `:minimal` read set grants. A lane could otherwise read any file other users or sessions left there and return it in its answer. A temporary root that holds a path the lane is given to read stays readable, because a deny outranks every read in codex's profile.
