- **diagnostics:** `scripts/diagnostics/eisv_substitution_probe.py` reports which tests reach the EISV estimator. It then runs them with the estimator's output frozen or replaced, with state frozen or advancing, and with a `proceed` or a `pause` verdict, and separates tests that need the estimator's state to advance from tests that need its values or its verdict. The findings are about test contracts, not runtime dependency.
