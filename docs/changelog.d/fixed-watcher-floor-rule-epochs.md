- **watcher:** The calibration floor that demotes a noisy (pattern, file class) no longer counts resolutions of a rule Watcher has since replaced. `calibration.PATTERN_RULE_EPOCHS` records when a pattern's rule last changed, and only findings detected at or after that time count toward its precision; a finding with no readable detection time does not count for a listed pattern. P006's entry is when #2447, which stopped P006 flagging handlers that already log, re-raise or return an error, reached the deploy checkout that runs Watcher. As of 2026-09-27, every false-positive dismissal behind the P006 app-code floor came from a 2026-09-23/24 triage of the rule before #2424 and #2447, where most flagged handlers were of the kind those changes dropped, and the floor was hiding current P006 findings on two days in three; that bucket is now unmeasured and does not demote. A change to what a pattern flags should move its entry, and the P006 rule's comment in `agent.py` says so.
