- **lease plane:** `file://` canonicalization now refuses a dangling symbolic link (`dangling_symlink`) instead of leasing the link's own name, and the governed `file_write` executor refuses to read, write or remove through a symbolic link in a leased path (`symlink_in_path`); new files are created exclusively. Crash recovery quarantines such a surface instead of hashing through the link. Overwriting an existing regular file still has a short check-to-open window, documented in `EffectFileOps`.
