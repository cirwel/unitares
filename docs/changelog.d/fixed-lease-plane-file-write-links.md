- **lease plane:** `file://` canonicalization now refuses a dangling symbolic link (`dangling_symlink`) instead of leasing the link's own name, and the governed `file_write` executor refuses to read, write or remove through a symbolic link in a leased path (`symlink_in_path`). Each file operation now runs in a short-lived `perl` helper that opens the path one directory at a time relative to the directory already held, with `O_NOFOLLOW`, so nothing can be swapped between a check and a use. Directories are opened search-only where the platform allows it, so a path through an ancestor that cannot be listed keeps working. An existing file is opened without `O_CREAT`, and a new one is created with `O_EXCL` inside the walked directory. It reads and writes only a regular, single-link file (`hardlinked_leaf`, `not_regular_file`), and opens never block on a FIFO. Compensation with no readable pre-image is refused without creating a file. Crash recovery reads the surface under the same rules and quarantines it instead of hashing through a link. If `perl` is missing, file operations fail closed (`file_helper_unavailable`).
