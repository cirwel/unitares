- **lease plane:** `file://` canonicalization now refuses a dangling symbolic link (`dangling_symlink`) instead of leasing the link's own name, and the governed `file_write` executor refuses to read, write or remove through a symbolic link in a leased path (`symlink_in_path`). It reads and writes only a regular, single-link file at the leased path (`hardlinked_leaf`, `not_regular_file`), creates new files exclusively, and overwrites an existing file only after confirming through the open descriptor that it is the file it checked (`path_changed`). Compensation with no readable pre-image is refused without creating a file. Crash recovery quarantines a surface with a link in its path instead of hashing through the link.
