- **watcher:** the scheduled sweep no longer counts a scan that did not run as a scan. `agent.py --file --exit-incomplete` exits 75 when a region was not scanned (model busy, call failed, reply unusable, file unreadable); the sweep then withdraws its marker and its hook lock, holds the watermark, and tries the file again, up to `UNITARES_WATCHER_SWEEP_MAX_TRIES` (default 3) per version of the file. Without the flag the exit status is unchanged, so the hook behaves as before (#3318).
