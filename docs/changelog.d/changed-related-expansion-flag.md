- **`UNITARES_ENABLE_GRAPH_EXPANSION` is renamed `UNITARES_ENABLE_RELATED_EXPANSION`.** The path it switches on adds the findings each top search result lists in its stored `related_to` column; it never read the AGE graph edges, so the old name described something it did not do. Behaviour is unchanged and the flag stays off by default. The old name is still read, with a one-time deprecation warning, when the new one is unset. Expansion over the graph edges themselves remains unbuilt.
