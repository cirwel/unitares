- **release:** the Promote Release `pin` job now regenerates `COMPATIBILITY.md`'s plugin and SDK rows and the public site's SDK pins with `scripts/ci/compat_component_rows.py`, as it already did the published-server row. The SDK is the newest `sdk-v*` tag in the release, and the job fails if PyPI does not serve it. The plugin is the release entry's `plugin-bundle-recut` version, and the job fails if that plugin release does not exist. A test now requires a Compatibility policy bullet for `VERSION`. These were hand edits, and v3.5.0 shipped with all of them still naming plugin v0.4.21 and SDK 0.5.0.
