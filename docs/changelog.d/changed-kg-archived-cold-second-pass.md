- **KG search reads archived and cold rows on a short page:** a query search that finds fewer than 3 active rows now runs a second pass over archived and cold rows. Rows from that pass come after every active row, carry `retrieval_tier="archived_cold_fallback"`, and their reported scores are halved. The response says so in `archived_cold_fallback`. An explicit `include_archived=false` or `include_cold=false` keeps that status out, and the string `"false"` now means false for both flags. Queryless listings and explicit `status` filters are unchanged. Interface contract 1.53.0.
