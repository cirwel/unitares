- **KG search reads archived and cold rows on a short page:** a query search that finds fewer than 3 active rows now runs a second pass over archived and cold rows. Rows from that pass come after every active row, carry `retrieval_tier="archived_cold_fallback"`, and their reported scores are halved. The response says so in `archived_cold_fallback`. The pass never costs the first page: when it fails, or would not finish in what the first pass left of the search's 15-second budget, the first page comes back alone with `archived_cold_fallback_error` saying why, in the lean digest too. An explicit `include_archived=false` or `include_cold=false` keeps that status out, and the string `"false"` now means false for both flags. Queryless listings and explicit `status` filters are unchanged. Interface contract 1.54.0.
