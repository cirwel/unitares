- **deploy:** the LaunchAgent preflight now follows a launcher script. When a plist runs a wrapper (for example one that reads a credential from the OS keychain and then execs the server) instead of naming the deploy worktree itself, the preflight accepts it if the wrapper is a readable text file that names the worktree. Before, every deploy of such a service refused with "the LaunchAgent plist does not point at the deploy worktree".
