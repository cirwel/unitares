- **agent PRs through the operator login:** a new advisory workflow labels `claude/*` and `codex/*` PRs authored by the operator's account `agent-via-operator-login`. Hosted Claude sessions have no App path (their GitHub proxy attaches the operator's credential), and the operator does not open PRs, so that authorship marks an agent act, not an operator act. The workflow never blocks and never edits a PR body. The workflow conventions describe the lane and require such sessions to footer their own onboarded uuid.
