- **A paused agent can no longer lift its own pause with `agent(action="resume")`.** Since #2667 that action accepts the agent itself or an operator token, and it has no risk or void gate, so a paused agent could call it on itself and resume at any risk, skipping the gate `self_recovery` applies. It now refuses a paused agent resuming itself with `PAUSE_SELF_RESUME_REFUSED` and the same `recovery` block a paused write gets; the pause still ends through `self_recovery`, dialectic, an operator, a safety net or expiry. The agent itself still resumes from `waiting_input` and still unsticks itself while active, and an operator token still resumes a paused agent. Interface contract 1.41.0: nothing is added, removed, retyped or renamed, and no input digest moves.
