- **knowledge search:** agent-to-agent channel messages rank below native findings in close relevance contests (operator decision, 2026-09-27). A discovery is `authority.tier="channel_message"` when it carries a `channel-<topic>` tag together with a `to-<agent>` tag, or a `[channel:<topic>]` summary prefix: the convention cross-harness coordination used on the KG before the lease-plane message transport replaced it (#1960). It gets the 0.55 multiplier imported memory already gets, so a channel note still ranks first when it is the only strong match, and it remains searchable. A `channel-` tag alone does not qualify (`channel-detection` is an ordinary topic). Imported memory keeps its own tier when a row carries both markers. A `channel-*` tag filter lifts the down-rank only from channel messages on that lane; every other row keeps its authority order, because a `channel-` tag can also be an ordinary topic. A filter made only of source-memory tags still reads that lane in raw order, but a mixed filter (tags match any-of, so it also returns ordinary findings) now keeps the authority order, which narrows the exemption source-memory tags had. Authority ranking also sees a pool of max(limit, 50) candidates before the page is cut: with hybrid and the reranker off it saw only `limit`, so a native finding just below a page of down-ranked rows could never be lifted, and `authority_mode="all"` still returns raw relevance order. Full and compact responses name the tier in `authority_policy` when a channel message is among the results. Measured 2026-09-27 on the relational table, 78 rows match the rule, 61 of them open. On the live KG, "PR merged review" at limit 10 went from channel notes in positions 1-3 and 6 of 10 to native findings in the top five and three channel notes at 6-8. Nothing is excluded, archived or retired.
