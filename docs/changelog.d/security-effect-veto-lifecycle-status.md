- **governed effects:** `POST /v1/effect-veto` now also vetoes a proposer whose `core.identities.status` is `archived`, `disabled`, `deleted` or `paused`, on every path including the unknown-proposer branch. Archival does not revoke continuity tokens, so an archived identity whose last check-in was clean could previously pass the verdict and tier gates until its token expired (about an hour). The check reads the deployment's own store; it implies no cross-deployment revocation.
