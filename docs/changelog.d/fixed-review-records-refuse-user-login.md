- **review gate:** `review_gate.py` no longer posts agent review records under a person's GitHub login. `review`, `record`, `dispose` and `sweep` (except `--dry-run`) post with whatever `gh` credential is in effect. Run directly rather than through the App runner, they posted under the operator's own account, so GitHub listed the operator as the author of an agent's review. These commands now read `GET /user` before any reviewer runs and refuse a user account, naming `unitares-github -- review ...` as the route to use. App installation tokens and the Actions token cannot read that endpoint, so they pass. `waive` still requires the operator's account, and `--emit` still prints a body without posting it.
