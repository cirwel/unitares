- **review gate:** `review_gate.py` no longer posts agent review records under a person's GitHub login. `review`, `record`, `dispose` and `sweep` (except `--dry-run`) post with whatever `gh` credential is in effect. Run directly rather than through the App runner, they posted under the operator's own account, so GitHub listed the operator as the author of an agent's review. These commands now read `GET /user` before any reviewer runs and proceed only on GitHub's refusal of that endpoint to an integration, which is how App installation tokens and the Actions token answer. A user account, an outage, a transport error or an unreadable reply all refuse, naming `unitares-github -- review ...` as the route to use. `waive` still requires the operator's account, and `--emit` still prints a body without posting it.
