- **Installation:** the managed Docker launcher reports native/Homebrew installation metadata and requires an explicit `--separate` choice with alternate, persisted host ports before creating a Docker stack alongside configured native services. CLI-only packages and reuse of an existing validated managed stack remain supported. Foreign or unlabelled Docker containers are refused before cloning. `unitares status` identifies the endpoint whose health/version it reports, with URL credentials omitted. Installation-choice guidance distinguishes packaging from optional capabilities and records the remaining Homebrew publication/lifecycle gates.
