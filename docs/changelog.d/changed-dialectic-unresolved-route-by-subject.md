- **ops:** `scripts/ops/dialectic_unresolved.py` routes standing objections to the next agent changing the same code instead of to the operator. `--touching PATH` (repeatable) keeps only reviews whose topic or conditions name one of the given repo-relative files, so a pre-PR gate can pass a branch's changed files; every emitted review now carries `subject_paths`. A review leaves the default listing once a PR whose body carries the line `Answers dialectic <session id>` has merged after the review opened (`answered_hidden`, shown by `--all`). The explicit line is required because a bare id usually cites a session as an example: #2735 quotes one it does not answer. The lookup is one batched, time-bounded `gh` search, found answers are cached, any failure hides nothing, and nothing is written to the database.
