- **PR queue & review hang mitigations:**
  - `scripts/ops/pr-babysitter.sh` auto-applies `review-requested` once when a queued PR is skipped for `review=NEUTRAL` or `review=ACTION_REQUIRED` (unless `review-requested` or `no-auto-review` is already set, or the policy/diff is unreadable), mirroring step 0 (`ready-when-validated`).
  - `scripts/dev/review_gate.py` skips `scope=fix` follow-up mode on `second_family_paths` when authors are known, the anchor covers fewer than two independent families, the chosen reviewer is an eligible missing family, and the full-review budget allows a full pass.
  - `scripts/dev/dependabot_triage.py` classifies single-package `in the actions group` minor bumps as `WOULD-MERGE` (while still holding major bumps).
  - `scripts/client/_check_freshness.py` adds `--merged-with REF` to detect CI merge-commit skill staleness before pushing using read-only `git merge-tree --write-tree` (failing closed with exit 2 if `git merge-tree` returns a non-conflict error such as exit 129 on Git < 2.38).
