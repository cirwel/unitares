- **PR queue & review hang mitigations:**
  - `scripts/ops/pr-babysitter.sh` excludes `skills/.attestations/` from diff fingerprinting (matching `review_gate.py`), preserves pinned approvals and `ready-when-validated` declarations across post-label pushes whose substantive diff fingerprint is unchanged (attestation restamps or clean local base merges), and auto-applies `review-requested` when a queued PR is skipped for `review=NEUTRAL` or `review=ACTION_REQUIRED` (unless `no-auto-review` is set or the policy/diff is unreadable).
  - `scripts/dev/review_gate.py` accepts a follow-up anchor whose `source.base` commit was deleted after a stacked parent squash-merged when `diff_key(base, source.head) == source.key` proves exact diff equality, and skips `scope=fix` follow-up mode on `second_family_paths` when the explicitly chosen reviewer family has no full-review anchor yet.
  - `scripts/dev/dependabot_triage.py` classifies single-package `in the actions group` minor bumps as `WOULD-MERGE` (while still holding major bumps).
  - `scripts/client/_check_freshness.py` adds `--merged-with REF` to detect CI merge-commit skill staleness before pushing using read-only `git merge-tree --write-tree`.
