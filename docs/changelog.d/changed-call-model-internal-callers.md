- **inference:** the two server-side callers of the deprecated `call_model` moved off it. The gateway's `query` intent classifier now asks `consult(effort='standard', privacy='local')` and reduces the reply to its first word, so "Search." or "**status**" still route; it no longer sets a 10-token cap, which `consult` does not take. A live run on the local model returned the bare intent (n=1). The knowledge-graph audit's optional model assessment (`use_model=true`) now uses the internal local lane (`call_local_llm`), so this housekeeping no longer bills Energy to the agent that asked for the audit. Its model budget is 45s, inside the audit's 60s handler timeout, so a slow model drops the assessment instead of failing the audit. The SDK's `call_model()` method is not changed here.
