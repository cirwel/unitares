- **identity: the identity surface's events reach the broadcaster again:** `_broadcaster()` in `src/mcp_handlers/identity/handlers.py` and `persistence.py` imported `broadcaster` from `src.broadcaster`, a name the module never defined (the singleton is `broadcaster_instance`). The accessors swallowed the ImportError and returned None, so every event they gate was skipped since those accessors landed in April 2026 (#70, #78): `identity_hijack_suspected` from the PATH 0 continuity-token gate (handler and middleware), the PATH 1 fingerprint and token-mismatch checks, the synchronous fingerprint check and the PATH 2 IP:UA pin check, plus `pg_session_collision` and `resident_fork_detected`. The warning log lines were written all along, but the WebSocket stream, `audit.events` and anything subscribed to them saw nothing. Every emission test patched the accessor with a mock, so none of them noticed. Both accessors now return `broadcaster_instance`, and a new test calls them unpatched and holds every `from src.broadcaster import ...` under `src/` to a name the module defines. The synchronous fingerprint check, which cannot await, scheduled its broadcast with a bare `loop.create_task`, which the loop references only weakly; now that it runs, it goes through `create_tracked_task`, which holds the task until it finishes. What changes for an operator: these events now appear on `/ws/eisv`, in `/api/events` and in `audit.events`. `identity_hijack_suspected` fires once per fingerprint mismatch in the default `log` mode, most of which come from benign same-agent twins, so a relay that posts every broadcaster event to chat (the Discord bridge does, with no repeat suppression for this type) posts one message per mismatch unless it suppresses or de-duplicates the type. The async emission sites await the broadcast, as the check-in's own EISV broadcast already does, so a request that emits one now waits for the WebSocket fan-out: bounded by the broadcaster's 2 s per-client send timeout plus 2 s to close a stalled client, which is then dropped, so a stalled dashboard costs that once. No gate decision, tool description, input schema or interface contract changed (#2559).
