- **github observer:** the `UNITARES agent:` footer of a pull request is now read from GitHub's own rendering of the body (`body_html`) instead of with a hand-written Markdown line scanner. GitHub has already resolved the Markdown and HTML, so a footer that is quoted, in code, struck through, linked, in a table or in `<details>` no longer counts, and prose such as `List<T>` no longer hides a later footer. HTML that is not GitHub's balanced output fails the read instead of being guessed at. No new dependency. The observer is still dry-run only (#3277).
