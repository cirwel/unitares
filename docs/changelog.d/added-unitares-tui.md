- **`unitares tui`:** a live, read-only terminal view over `unitares status --json` and `unitares tools`. It shows server health, agent tiers and the resident table with a per-resident EISV, coherence, risk, check-in history and recent-finding drill-in. It uses the standard library only and reuses the CLI's URL and token handling. `unitares tui --once` prints a plain snapshot without a TTY.
