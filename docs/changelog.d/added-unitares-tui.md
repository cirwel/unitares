- **`unitares tui`:** a live, read-only terminal view over `unitares status --json` and `unitares tools`. It shows server health, agent tiers and the resident table with a per-resident EISV, coherence, risk, check-in history and recent-finding drill-in. It uses the standard library only and reuses the CLI's URL and token handling. `unitares tui --once` prints a plain snapshot without a TTY, `--once --json` a stable machine-readable one (schema `unitares.tui.snapshot.v1`), and `NO_COLOR` or `--no-color` turns color off.
