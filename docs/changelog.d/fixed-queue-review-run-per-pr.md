- **queue:** the governance-sensitive gate in `scripts/ops/pr-babysitter.sh` now reads only the `review` runs tagged for the PR it is deciding (`unitares-review:<pr>:<head>`). Two open PRs on one head share their check runs, and the newest run on the head used to decide, so another PR's two-family pass could hide this PR's operator waiver. A head that carries only other PRs' runs now counts as not yet reported. Before arming, the queue also re-reads the PR body, so an `Expected effect:` line removed after the tick began stops the arm.
