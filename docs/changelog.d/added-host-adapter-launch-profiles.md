- **Host adapters:** with `UNITARES_ORCHESTRATOR_PROFILES=1`, the codex, claude and antigravity adapters send only the orchestrator's `host.*` launch-profile request (`{profile, vars}`: the prompt, an optional model, and a deadline where the profile takes one), never a command or an environment. A refused profile spawn is reported as `spawn_rejected`, and nothing is retried as a raw spawn. Off by default; turn it on once the orchestrator serves the generated profiles file (inference-hosts-config-v0 step 4b).
