- **review gate:** the Antigravity (`agy`) reviewer reads the diff and the changed files from its temporary workspace (`diff.patch`, and `files/<repository path>` for each changed file's committed text) instead of one inlined command-line argument, so the old ~120 KB cap is gone: PR #2470's 143 KB diff could not be reviewed by Antigravity at all, and every round fell back to Claude. `agy` reads these with its own file tool, which needs no permission grant inside its workspace; a shell command it reaches for is still denied, and the resume prompt now says file reads work. Content still comes only from committed git objects, never the working tree, symlinks or paths outside the repository. Changed files named `AGENTS.md`, `GEMINI.md`, `CLAUDE.md` or under `.agents/`/`.gemini/` are written with a `.review-copy` suffix so a PR cannot configure its own reviewer. The default model is Gemini 3.1 Pro (High) at full effort, overridable with `REVIEW_AGY_MODEL` (`default` leaves the choice to `agy`); it was chosen on two PRs, where it was the only model that found real defects, so it is a starting point rather than a measured result. The shared review budget rises from 1,800 to 2,400 seconds, since Pro needed 983 s for #2470 and the first of two attempts used to get only 900.
