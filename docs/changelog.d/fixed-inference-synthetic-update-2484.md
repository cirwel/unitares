- **inference accounting:** `run_model_inference` and `run_delegated_inference` no longer run a synthetic `monitor.process_update` on the calling agent's state (`#2484`), so `consult`, `call_model`, and `delegate_inference` stop advancing caller EISV trajectories, appending synthetic `decision_history` entries, resetting `_prev_confidence` / `_last_prediction_id`, or writing `auto_attest` rows with server-derived confidence (`~0.557`). Direct `call_model` and `delegate_inference` calls now write a Postgres-only `audit.events` row (`event_type='inference_call'`, `unitares.inference_call.v1`, `confidence=0.0`) carrying route, privacy class, and outcome without prompt or response text, while `consult` continues to write `event_type='consultation'`. What this does not do: it does not remove `energy_cost` from the `call_model` / `delegate_inference` response envelopes or change `call_model`'s deprecation schedule (#2484).
