- **sdk:** `delegate_inference()` is sent once and never retried, on both clients. Before, a timeout or transport error was retried, and because the outer `timeout_s + 75` never raised the HTTP client's own 30s timeout, a delegation longer than 30s on the MCP transport could be re-sent while the first child was still running, spending subscription quota twice and starting a second orchestrator execution. The docstring now says the HTTP client's `timeout` bounds the call. Uses `call_tool(retry=False)` from the `consult()` change.
