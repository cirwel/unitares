- **agent response envelopes:** three caller signals that the friendly default responses dropped now survive. A bounded `sync_state` (compact, mirror, or auto resolving to either) carries the check-in's `warnings` at the top level; they were dropped in every bounded mode, although a warning is one of the formatter's own reasons to expand auto to mirror and no later read returns them. A proceed that carries one is no longer trimmed as routine. A lean `search_shared_memory` carries `state_summary.limit_clamped_from` when the server clamped `limit`. It also carries `imported_omitted` with its hint when a queryless listing left unpromoted imported memory out: the handler's lean projection now keeps both, so the envelope's existing lift of them is no longer dead. `tests/test_envelope_required_fields.py` declares, per experience alias, the fields an agent must carry out of the default response (ids it passes back and documented signals no later read returns). It asserts each one survives with the minted value, and fails for a new experience alias until its set is declared. The per-alias classification is in `docs/analysis/envelope-field-audit-2026-10-19.md` (#2125).
