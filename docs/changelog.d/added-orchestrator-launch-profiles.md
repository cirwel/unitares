- The agent orchestrator can spawn named launch profiles (`AGENT_ORCHESTRATOR_PROFILES_FILE`): a request names a profile and fills only its declared variables, the child environment is built from the profile (non-inherited variables unset, secrets bound to the profile and redacted from output), and per-profile concurrency and hourly limits apply. `AGENT_ORCHESTRATOR_RAW_SPAWN` defaults to `deny` whenever a profiles file is configured. Without a profiles file nothing changes (inference-hosts-config-v0 step 4a).
