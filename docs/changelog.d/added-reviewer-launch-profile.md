- **Dialectic reviewer:** with orchestrated review and `UNITARES_ORCHESTRATOR_PROFILES=1`, the reviewer is spawned only as the `dialectic.reviewer` launch profile: the request carries the session id alone, keyed on a digest of the thesis so a later round never replays an earlier spawn. A refused spawn or a fast crash leaves the session awaiting facilitation (`reviewer_profile_refused`, `reviewer_profile_exited`) instead of running the in-process reviewer. Through the lease plane, the governed payload is the closed `{profile, vars, context_sha256}` form: the plane refuses any other key in it, forwards only the profile and its variables, and provisions no lineage, which the profile decides (inference-hosts-config-v0 step 4b).
