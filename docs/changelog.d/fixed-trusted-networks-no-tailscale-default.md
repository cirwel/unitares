- **REST trusted networks:** the local-posture auth bypass no longer trusts `100.64.0.0/10` by default. That range is where Tailscale assigns addresses, and some ISPs also use it for carrier-grade NAT. Building it in meant every install trusted one operator's tailnet layout. Loopback and the RFC1918 private ranges stay built in. An operator whose callers come over a tailnet or another overlay adds it with `UNITARES_TRUSTED_NETWORKS` (comma-separated CIDRs). The LaunchAgent template and `.env.example` document the setting. **Upgrade note:** a deployment that relied on the implicit Tailscale trust must set `UNITARES_TRUSTED_NETWORKS=100.64.0.0/10`, or its tailnet callers will get 401 on REST and the dashboard WebSocket.
