- **BEAM node cookies no longer appear on any command line.** The agent-orchestrator and lease-plane start scripts passed their Erlang cookie with `elixir --cookie`, which puts it in `beam.smp`'s argv, readable by any process listing; node access is arbitrary code execution, and the orchestrator's cookie reached an agent transcript that way on 2026-10-15. Each service now receives the cookie in its environment, starts its named node at boot (`NodeDistribution`), sets the cookie, and removes the variable before any child process spawns. `scripts/ops/beam-attach.sh` and the lease plane's `hot-reload.sh` give their client node a private `~/.erlang.cookie` (mode 400, removed on exit) instead of `--cookie`. `-args_file` and `ERL_AFLAGS` were tested and rejected: the `erl` launcher expands both back into the emulator's argv. Takes effect when each service restarts.
