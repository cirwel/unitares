### Compose upgrade correction

The five-tool default and named dispatch are in v2.22.0, but its Compose file
does not pass `GOVERNANCE_TOOL_MODE` into the server. Setting it only in the
checkout's `.env` does not restore the advertised 29-tool `lite` surface.
The forwarding fix is being prepared for v2.22.1; it is not yet a published
installation target.

For an existing v2.22.0 checkout, create `docker-compose.lite.yml` with:

```yaml
services:
  governance-mcp:
    environment:
      GOVERNANCE_TOOL_MODE: lite
```

Then rebuild/recreate the service with both files and reconnect the MCP client:

```bash
docker compose -f docker-compose.yml -f docker-compose.lite.yml up -d --build --wait --force-recreate governance-mcp
```

Continue supplying the override file on later Compose invocations. For a
non-Compose installation, put the variable in the actual server process's
environment and restart it. Discovery controls which tools a schema-driven
client offers; continued named dispatch does not guarantee unchanged default
client workflows. The profiles do not replace authorization checks.
