# v2.22.1 maintenance release

Status: tagged and published from `release/2.22` on 2026-09-08, and
forward-merged into master by #2209 on 2026-09-13. The notes below describe the
candidate this release was cut from; the publication checklist further down is
complete.

The candidate starts at the published v2.22.0 tag and backports the release
corrections from #2092. It restores the documented Compose `.env` override for
operators retaining the 29-tool `lite` surface. Rebuild/recreate
`governance-mcp` and reconnect MCP clients after changing that setting.

The five-tool default and all v2.22.0 registered callable names, input schemas,
lifecycle envelopes and skills are unchanged. `direct_resume_if_safe` remains
in this maintenance line. The later removal on master is outside this patch.
No database migration, SDK release or plugin re-cut is required for this branch.
Plugin v0.4.17 matches the unchanged bundle; this is byte parity, not new host
end-to-end validation.

## How this release was cut

v2.22.1 was prepared from tag `v2.22.0` (`b1360809`) on `release/2.22`,
rather than from master. It backported #2092 and the release-evidence
corrections while preserving the published callable surface and skills. It
was tagged and published from `release/2.22` on 2026-09-08, and its history
was forward-merged into master by #2209, which makes the maintenance tag an
ancestor of later mainline releases, as the release-range gate requires.

The v2.22.0 tag and release were left intact; their correction is recorded in
[`2.22.0-errata.md`](2.22.0-errata.md). A merge into a maintenance branch does
not deploy the master-only public Pages workflow. The general procedure for
any release, maintenance or mainline, is
[`../operations/RELEASE_PROCESS.md`](../operations/RELEASE_PROCESS.md).
