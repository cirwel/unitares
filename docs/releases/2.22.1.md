# v2.22.1 maintenance release candidate

Status: prepared for independent review; not tagged or published.

The candidate starts at the published v2.22.0 tag and backports the release
corrections from #2092. It restores the documented Compose `.env` override for
operators retaining the 29-tool `lite` surface. Rebuild/recreate
`governance-mcp` and reconnect MCP clients after changing that setting.

The five-tool default and all v2.22.0 registered callable names, input schemas,
lifecycle envelopes and skills are unchanged. `direct_resume_if_safe` remains
in this maintenance line. The later removal on master is outside this patch.
No database migration, SDK release or plugin re-cut is required for this branch.
Plugin v0.4.17 matches the unchanged bundle; this is byte parity, not new host
end-to-end validation.

## Publication checklist

1. Review the diff against v2.22.0, the upgrade instructions and version choice.
2. Require all candidate CI, including the actual Docker MCP checks, to pass.
3. Merge only into `release/2.22`, then tag that exact merge commit as v2.22.1.
4. Publish the release and verify both container architectures, digest, SBOM
   and build provenance. Leave v2.22.0's tag unchanged.
5. Append the v2.22.0 errata to its existing release body.
6. Advance public install pins in a separate master PR after verification.

Until these steps are complete, public installation examples remain pinned to
v2.21.0. Source preparation, merge, tagging and publication are separate states.
