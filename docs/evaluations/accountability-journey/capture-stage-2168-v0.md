## 8. What this says about the audit's own claims

**"Comparative reconstruction against Git, PR, CI, the harness transcript and ordinary traces is unmeasured" (audit lines 174 to 175, and the executive verdict at 11 to 12).** The claim was accurate before this exercise; nothing of this kind had been run. It is now measured once, on one natural-capture incident, for the Git/PR/CI part of the control only, and for the capture stage only. The result is a large asymmetry on the unit (87 incident facts against 56 facts whose incident-specific members are all absences) and a real increment on the class, the substrate and the aftermath. It does **not** close the claim, for three reasons the audit itself states: the control lacked the harness transcript that line 328 includes, no oracle was assembled (lines 337 to 339), and the exercise ran the arms disjoint rather than as control versus control-plus-candidate (line 329).

**"The existing equal-facts accountability-journey rehearsal tied 1.000 to 1.000, so any next test must separate capture from retrieval rather than repeat only the tied stage" (audit lines 176 to 178).** This exercise separates them by construction and lands on capture, the stage the audit says the tie could not answer. The capture result is not a tie: lopsided to the artifacts on incident facts (54 pure artifacts-only ledger rows against 0 UNITARES rows about the unit) and lopsided to UNITARES on substrate, class and process context (30 UNITARES-only rows). The two results are consistent rather than contradictory: equalise the inputs and the arms score alike, because the difference is whether anything entered the record at all. One new caution for the pilot: the stages can contaminate each other. Six of pass 2's facts were reachable only through seed tokens taken from pass-1 artifacts (P2 F8, F9, F10, F11, F17, F43), so a capture run launched alongside a control run is not automatically independent of it.

**"This is complementary only if UNITARES can show that its upper layer produces a better accountability result than storing the Relay trajectory beside Git and CI records" (audit line 148).** This exercise is a partial, one-incident read on exactly that comparison, and the reading is mixed and instructive.
